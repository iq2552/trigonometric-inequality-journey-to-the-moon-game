## 4. Bull case / Bear case

*หมายเหตุ: ข้อมูลด้านล่างมาจาก web search (Rem) เท่านั้น เป็นข่าว/ความเห็นภายนอก ไม่ใช่ตัวเลขจาก 10-K หรือ transcript ที่ verify ได้*

**Bull Case**
- Analyst หลายรายอัปเกรด rating หลังผลประกอบการ: Raymond James ขึ้นเป็น Strong Buy (price target $315→$400), Cantor Fitzgerald ขึ้นเป็น Overweight (price target $310→$370) โดยอ้างอิงมุมมอง Google Cloud และ Search ที่แข็งแรงขึ้น (source: web search 2026-08-09)
- P/E (trailing) อยู่ที่ ~17.87x ซึ่งเป็นระดับต่ำสุดตั้งแต่ปี 2019 ตามรายงานข่าว — เป็นข้อมูลเชิงราคาที่น่าสนใจสำหรับแนว value investing แต่ต้องเทียบกับตัวเลข earnings จริงจาก 10-K ก่อนสรุปว่าถูกหรือแพง (source: web search 2026-08-09)
- Alphabet ออกหุ้นกู้ investment-grade $25 พันล้านสำเร็จ โดยมียอดจองซื้อสูงถึง ~$115 พันล้าน สะท้อนว่าตลาดตราสารหนี้ยัง confident ในความสามารถชำระหนี้ของบริษัท แม้จะกู้เพิ่มเพื่อ AI capex (source: web search 2026-08-09)

**Bear Case**
- Chief Scientist Jeff Dean และนักวิจัย AI ระดับสูงหลายคน (Sanjay Ghemawat, Quoc Le, Oriol Vinyals) ลาออกพร้อมกันเพื่อไปตั้งสตาร์ทอัพใหม่ ระหว่างเดียวกัน Demis Hassabis ก็ลงจากตำแหน่ง CEO ของ DeepMind — เป็นการเปลี่ยนแปลงผู้นำสาย AI ที่เกิดขึ้นพร้อมกันหลายคนในช่วงต้นเดือนสิงหาคม 2026 (source: web search 2026-08-09)
- บริษัทปรับเพิ่ม capex guidance สูงสุดถึง $190 พันล้าน ซึ่งเป็นเหตุผลหลักที่หุ้นร่วง 7%+ ในวันประกาศผลประกอบการ (22 ก.ค. 2026) — นักลงทุนบางส่วนกังวลว่าการลงทุน AI infrastructure จำนวนมากนี้จะแปลงเป็น return ที่คุ้มค่าเมื่อไหร่ (source: web search 2026-08-09)
- คดี antitrust: DOJ และกลุ่มอัยการรัฐยื่นอุทธรณ์คำตัดสินที่ให้ Google เจอแค่ behavioral remedies (ไม่ใช่ structural breakup) พร้อมยื่น cross-appeal ขอให้พิจารณาบังคับขาย Chrome ใหม่ คดีมีแนวโน้มลากยาวถึงต้นปี 2027 (source: web search 2026-08-09)

## 5. Kill conditions

- ถ้าการลาออกของทีมผู้นำ AI ต่อเนื่องเป็นระลอกโดยไม่มีการแต่งตั้งผู้นำที่น่าเชื่อถือเข้ามาแทนที่ชัดเจน
- ถ้า capex ด้าน AI infrastructure ยังเพิ่มขึ้นต่อเนื่องหลายไตรมาส โดยที่ Cloud/Search revenue ไม่โตตามในอัตราที่สมเหตุสมผล
- ถ้าศาลอุทธรณ์ตัดสินให้ต้องทำ structural remedies จริง (เช่น บังคับขาย Chrome หรือแยกธุรกิจ) ซึ่งจะกระทบโครงสร้างธุรกิจหลักโดยตรง

## 6. What to ask before owning it

1. Capex $190 พันล้านที่เพิ่มขึ้น จะสร้าง return ให้ Cloud/AI business แค่ไหน และใช้เวลานานเท่าไหร่ถึงจะเห็นผล? (ต้องดู 10-K/transcript จริงเพื่อตอบ)
2. การลาออกของ Jeff Dean และทีม AI ระดับสูง กระทบ execution ของ Gemini roadmap มากแค่ไหนในทางปฏิบัติ ไม่ใช่แค่ headline?
3. ผลของคดี antitrust ถ้าออกมาแย่ที่สุด (บังคับขาย Chrome หรือแยกธุรกิจ) จะกระทบรายได้โฆษณาหลักแค่ไหน?
4. P/E ที่ต่ำสุดตั้งแต่ 2019 สะท้อนว่าตลาดกำลังกังวลอะไรเป็นพิเศษ หรือเป็นโอกาสที่แท้จริง — ต้องตรวจสอบตัวเลขกำไรจริงจาก 10-K ก่อนสรุป
5. ก่อนตัดสินใจ ควรกลับมาอ่าน 10-K และ earnings call transcript จริงของ Alphabet ก่อน เพราะ brief นี้ยังไม่มี source เหล่านั้นเลย — จะหาไฟล์มาเพิ่มใน `sources/GOOGL/` เมื่อไหร่?
