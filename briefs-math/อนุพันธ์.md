## 1. วิธีใช้

*(Source: Rem-Math — เว็บ เนื่องจากไม่มีไฟล์เนื้อหาในโฟลเดอร์)*

**ความหมายเชิงเรขาคณิต:** อนุพันธ์ = อัตราการเปลี่ยนแปลงของ y เทียบกับ x หรือมองเป็นความชันของกราฟ ณ จุดหนึ่งๆ

**Power Rule:** d/dx[xⁿ] = n·xⁿ⁻¹ — ใช้ได้กับ n ทุกแบบ (บวก ลบ เศษส่วน) เช่น d/dx[x^(1/2)] = (1/2)x^(-1/2)

**Product Rule:** (fg)' = f'g + fg' — สำหรับ 3 ฟังก์ชัน (fgh)' = f'gh + fg'h + fgh' **ข้อควรระวัง:** อนุพันธ์ของผลคูณ ≠ ผลคูณของอนุพันธ์

**Quotient Rule:** (f/g)' = (f'g − fg') / g² — mnemonic: **"low d-high, minus high d-low, all over low-squared"**

**เลือกใช้กฎไหน:** เทอมบวก/ลบกัน → แยกหาทีละเทอม, สองฟังก์ชันคูณกัน → product rule, ฟังก์ชันหารกัน → quotient rule, ฟังก์ชันประกอบ (เช่น (3x+2)³) → chain rule

**ข้อ 19)** y = 3/√(x+2)
1. เขียนใหม่เป็นเลขยกกำลัง: y = 3(x+2)^(-1/2)
2. ใช้ chain rule: y' = 3·(-1/2)(x+2)^(-3/2)·1
3. **y' = -3 / [2(x+2)√(x+2)]**

**ข้อ 20)** y = (2x⁷ − x²)(x-1)/(x+1)
1. ให้ u = 2x⁷-x², v = (x-1)/(x+1)
2. u' = 14x⁶ - 2x
3. v' (quotient rule): [(1)(x+1)-(x-1)(1)]/(x+1)² = 2/(x+1)²
4. Product rule: y' = u'v + uv' = (14x⁶-2x)·(x-1)/(x+1) + (2x⁷-x²)·2/(x+1)²
5. รวมเศษส่วน: **y' = [(14x⁶-2x)(x²-1) + 2(2x⁷-x²)] / (x+1)² = (14x⁸+4x⁷-14x⁶-2x³-2x²+2x) / (x+1)²**

**หาอนุพันธ์ ณ จุดที่กำหนดให้:**

**ข้อ 1)** f(x) = 2x³ − 1/√x ที่ x=1
1. f(x) = 2x³ - x^(-1/2)
2. f'(x) = 6x² + (1/2)x^(-3/2)
3. f'(1) = 6 + 1/2 = **13/2**

**ข้อ 2)** f(x) = (1/5)x⁵ - (1/3)x³ + (1/2)x² - 4x + 5 ที่ x=1
1. f'(x) = x⁴ - x² + x - 4
2. f'(1) = 1-1+1-4 = **-3**

**ข้อ 3)** f(x) = (2x²-3x+1)(x-x²) ที่ x=-1
1. u=2x²-3x+1, v=x-x², u'=4x-3, v'=1-2x
2. ที่ x=-1: u=6, v=-2, u'=-7, v'=3
3. f'(-1) = u'v+uv' = (-7)(-2)+(6)(3) = 14+18 = **32**

**ข้อ 4)** f(x) = (2x-1)/(x+1) ที่ x=2
1. Quotient rule: f'(x) = [2(x+1)-(2x-1)]/(x+1)² = 3/(x+1)²
2. f'(2) = 3/9 = **1/3**

**กำหนดให้ f(4)=3 และ f'(4)=-5 จงหา g'(4):**

**ข้อ 1)** g(x) = √x·f(x)
1. g'(x) = (1/2)x^(-1/2)·f(x) + √x·f'(x)
2. g'(4) = (1/2)(1/2)(3) + (2)(-5) = 3/4 - 10 = **-37/4**

**ข้อ 2)** g(x) = f(x)/x
1. g'(x) = [f'(x)·x - f(x)]/x²
2. g'(4) = [(-5)(4)-3]/16 = **-23/16**

## 3. จุดที่มักผิด

*(Source: Megumin-Math + Rem-Math)*
- ลืมแปลงราก/เศษส่วน (1/√x, √(x+2)) เป็นรูปเลขยกกำลังก่อนดิฟ หรือดิฟเลขชี้กำลังลบผิดเครื่องหมาย (ลืมว่า -(-1/2) = +1/2)
- โจทย์ chain rule (ข้อ 19) ลืมคูณด้วยอนุพันธ์ของฟังก์ชันข้างใน แม้จะเท่ากับ 1 ก็ต้องเขียนขั้นตอนให้ครบ
- โจทย์ผลคูณ/ผลหารซับซ้อน (ข้อ 20, ข้อ 6-9 ของแบบฝึกหัด 2.4): เลือกได้ทั้งขยายพหุนามก่อนแล้วดิฟ หรือใช้ product/quotient rule ตรงๆ แต่เสี่ยงคูณกระจายเครื่องหมายผิดถ้าขยายเอง
- Quotient rule ลำดับการลบ (u'v - uv')/v² สลับลำดับไม่ได้ เพราะการลบไม่ commutative — เข้าใจผิดว่า product rule คือ "ดิฟแต่ละตัวแล้วคูณกัน" ก็เป็นจุดพลาดที่พบบ่อยเช่นกัน
- ข้อที่ให้หาค่า ณ จุดเฉพาะ (เช่น x=1, x=-1) มักลืมขั้นตอนสุดท้ายคือแทนค่ากลับหลังดิฟเสร็จ หรือแทนค่าใน f(x) เดิมแทนที่จะแทนใน f'(x)
- โจทย์แบบนามธรรม (กำหนด f(4), f'(4) มาแล้วหา g'(4)) มักสับสนพยายามหาสูตร f(x) จริงๆ ซึ่งทำไม่ได้และไม่จำเป็น — ใช้ product/quotient rule กับ f ในฐานะฟังก์ชันนามธรรมแล้วแทนค่าตัวเลขตอนท้ายพอ
- y = (x³+2)/x ควรลดรูปเป็น x²+2/x ก่อนดิฟด้วย power rule จะง่ายกว่าใช้ quotient rule ตรงๆ

## 4. แนวข้อสอบ

*(Source: Megumin-Math + Rem-Math)*
- หาอนุพันธ์ฟังก์ชันที่มีเทอมราก/เลขชี้กำลังเศษส่วนผสมพหุนาม — ต้องแปลงเป็นเลขยกกำลังก่อน
- หาอนุพันธ์ผลคูณสองฟังก์ชัน (product rule) ทั้งแบบขยายพหุนามได้ง่ายและแบบยุ่งยาก (เลขชี้กำลังสูง)
- หาอนุพันธ์ผลหารสองฟังก์ชัน (quotient rule) โดยเฉพาะรูปแบบ (ax+b)/(cx+d)
- "หาอนุพันธ์ ณ จุดที่กำหนด" — ต้องหาสูตร f'(x) ก่อนแล้วค่อยแทนค่า x
- โจทย์นามธรรมที่กำหนด f(a), f'(a) มาให้ แล้วให้หา g'(a) จาก g ที่สร้างจาก f ผ่าน product/quotient/chain — วัดความเข้าใจกฎมากกว่าคำนวณตัวเลข
- โจทย์ผสม product rule + quotient rule ในข้อเดียว — ยากสุด ควรฝึกแยกสูตรทีละส่วนก่อนรวมคำตอบ
- (แนวจากเว็บ) ฟังก์ชันประกอบที่ต้องใช้ chain rule เช่น f(x) = (3x+2)³
